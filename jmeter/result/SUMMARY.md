## 4. 数据口径

- 原始 JTL 约 434 MB，未提交到 Git；本文件是唯一入库的统计摘要。
- 每轮 50 线程、5s ramp-up、60s 持续；预热线程组 20 线程 × 20s，预热样本已剔除。
- 数据集：50 个账号、500 个帖子（tid 1001–1500）；like/collect = 60/40，true/false = 60/40。
- 压测期间关闭/放宽 IP 限流阈值以避免 429；过滤器仍对每个请求计数。
- JTL 的 `success` 字段来自 JSON 断言 `$.code == 200`，不是只看 HTTP 200。
- TPS/RT/P99 可由本脚本复算；jstack、`CLIENT LIST`、SQL 91s/418ms、启动耗时属于当次手工诊断，不在 JTL 中。
