# my-project-frontend

校园论坛前端，Vue 3 + Vite + Element Plus。

完整的项目介绍、功能、压测与启动方式见仓库根目录的 [README.md](../README.md)。

## 开发

```bash
npm install
npm run dev
```

默认访问 `http://localhost:5173`，后端 API 地址在 `src/main.js` 的 `axios.defaults.baseURL`（默认 `http://localhost:8080`）。

## 构建

```bash
npm run build
```
